# Portfolio de Gonçalvès Cédrick

Bienvenue sur le dépôt de mon portfolio professionnel. Ce site vitrine présente mon profil de développeur Web & Mobile Fullstack, mes compétences techniques, mes expériences, ainsi que mes projets récents.

## 🚀 Aperçu du projet

Ce portfolio a été conçu pour être :
- **Rapide et performant** : Développé sans frameworks lourds pour un chargement instantané.
- **Bilingue (Français / Anglais)** : Un système d'i18n en JavaScript natif permet de changer la langue sans rechargement de page.
- **Thème Sombre / Clair** : Adaptation aux préférences de l'utilisateur ou du système.
- **Responsive** : Interface optimisée pour mobile, tablette, et desktop.
- **Interactif** : Intégration d'effets de "machine à écrire", de filtrage de projets, et de notifications fluides.

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique et accessible.
- **Tailwind CSS (via CDN)** : Design moderne, utilitaire et responsive.
- **JavaScript (Vanilla)** : Logique de la page (filtrage, modale, gestion des thèmes, animations au scroll, traductions).
- **Google Fonts** : Police *Inter* pour une typographie épurée et moderne.
- **SVG natifs** : Icônes légères et intégrées directement dans le code.

## 📁 Structure du Projet

```text
/
├── index.html        # Page principale (structure et contenu)
├── css/
│   └── style.css     # Styles personnalisés (animations, variables, composants spécifiques)
├── js/
│   └── script.js     # Logique de l'application (modales, filtres, thème, traductions)
└── assets/           # Images, PDF (CV), et captures d'écran des projets
```

## 🔧 Comment lancer le projet en local ?

Le projet ne nécessitant aucune étape de compilation complexe, vous pouvez le visualiser directement :

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/Goncalvescedrick/portfolio.git
   ```
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne.
3. *Alternative :* Pour une meilleure expérience (surtout avec certains scripts JS), vous pouvez utiliser un serveur local comme Live Server sur VS Code, ou via Python :
   ```bash
   python -m http.server 8000
   ```
   Puis rendez-vous sur `http://localhost:8000`.
